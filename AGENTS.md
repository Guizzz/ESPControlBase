# TempStation — AGENTS.md

ESP8266 temperature/humidity station. PlatformIO, Arduino framework, board `esp12e`.

## Build & dev

```bash
pio run                  # build
pio run -t upload        # build + upload to board
pio run -t monitor       # serial monitor (9600 baud)
pio test                 # test runner (test/ is empty scaffold)
```

## Project structure

| Path | Role |
|---|---|
| `src/main.cpp` | Entrypoint (`setup()` → `loop()`) |
| `include/config.h` | **All** pin assignments, WiFi/MQTT credentials, device ID |
| `include/GY_21.h` | GY-21 (Si7021) I2C sensor driver, address `0x40` |
| `lib/displayManager/` | OLED SSD1306 128×64, address `0x3C`, auto-off on timeout |
| `lib/mqttManager/` | WiFi + MQTT (PubSubClient), command handlers, periodic status |
| `lib/requestManager/` | Legacy HTTP server on port 80 (REST fallback) |
| `lib/threadManager/` | Cooperative scheduler, intervals in ms |

## Wiring / I2C

- SDA = D5, SCL = D6
- LED: clock = D2, data = D7 (Grove Chainable RGB LED)
- Relay = D1 (GPIO5), active HIGH
- Flash button = D3 (GPIO0), `INPUT_PULLUP`, `LOW` = pressed

## Critical gotchas

- **`config.h` contains real WiFi SSID/PSK and MQTT host** — do not commit with secrets. Treat the whole file as sensitive.
- `.vscode/c_cpp_properties.json` and `launch.json` are auto-generated by PlatformIO — never edit manually.
- Serial baud is 9600.
- Uses **ArduinoJson 7.x** (`JsonDocument`, not `DynamicJsonDocument`).
- `Wire.begin(SDA, SCL)` is explicit (ESP8266 I2C pins are configurable).

## Communication

- **MQTT**: connects to `raspberrypi.local:1883`, publishes status JSON every 5 s, subscribes to commands `set_relay` (bool `value` / toggle) and `set_led` (bool `value` / toggle).
- **HTTP** (legacy): `GET /get_temp` → `{temp, hum}`, `POST /set_relay` and `POST /set_led` accept JSON body with optional `value` field.
